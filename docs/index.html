video-ai-dub

Replace the speech in a video with a natural AI voice-over timed to the original, add an optional title intro and a Thank You end card, then polish the result with cuts, mutes, shifts and extra narration. Needs only an OpenAI API key and ffmpeg.

Python 3 OpenAI Whisper + TTS + GPT ffmpeg Pillow No third-party Python packages besides Pillow

Overview

Three command-line tools share one package, dubber/.

Tool 1

ai_dub.py

Seven-step pipeline: extract audio, transcribe, validate, rewrite script, synthesize speech, build cards, assemble the final video. Auto or human-in-the-loop mode.

Tool 2

demo.py

Demo studio. Project folder with versions, undo and redo. Queue edits (cut, mute, shift-audio, narrate, replace-voice), check them, apply in one render pass.

Tool 3

video_edit.py

Stateless one-shot edits. cut removes ranges, narrate adds AI voice at a time, info prints details.

The original video is never modified. Every tool writes into a separate folder next to it and logs every run to JSON.

Usage

1. Set up

brew install ffmpeg
python3 -m pip install pillow
echo 'export OPENAI_API_KEY=sk-...' >> ~/.zshrc && source ~/.zshrc

2. Dub a raw recording: ai_dub.py

python3 ai_dub.py my_video.mp4
python3 ai_dub.py my_video.mp4 --context-file project_context.txt --voice nova

You are asked for a title (Enter skips the intro) and a mode.

Auto

Runs all seven steps with no questions.

Human-in-the-loop

Asks for context and key terms, then pauses twice: after validation (raw transcript) and after the rewrite (script).

Key at a review pauseAction
eFull-screen terminal editor (curses). Up/Down or j/k move, Enter edits a line, s saves, q cancels.
oOpen the markdown file in your text editor, save, press Enter back in the terminal.
vShow the lines again.
sScript pause only. Give the AI a suggestion for the whole script.
pProceed.

Run again on the same video and a menu appears: a all steps, 5 only step 5, 5+ step 5 onward, q quit. Unchanged speech lines are cached, so re-running audio only pays for edited lines.

Pause marker inside narration: Click Next. [pause 2s] Then Start. ([pause] = 1 s, max 10 s).

Project knowledge goes in a text file passed with --context-file. A line starting with Terms: also biases transcription.

3. Polish a video: demo.py

python3 demo.py                                   # guided menu
python3 demo.py new video.mp4                     # start a project
python3 demo.py map video.demo                    # show where speech is
python3 demo.py add video.demo "cut 02.58-03.06" "shift-audio 00.58 earlier 1s"
python3 demo.py script video.demo edits.txt       # edits from a file
python3 demo.py status video.demo
python3 demo.py plan video.demo                   # check, render nothing
python3 demo.py where video.demo 03.49            # time after pending cuts
python3 demo.py preview video.demo                # low quality, not saved
python3 demo.py apply video.demo [--snap] [--yes]
python3 demo.py undo video.demo                   # and redo
python3 demo.py export video.demo --out final.mp4
python3 demo.py dub raw_recording.mp4             # run ai_dub flow
Edit wordExampleEffect
cutcut 02.58-03.06Remove that part of picture and sound. Re-encodes video.
mutemute 02.05-02.08Silence audio in that part.
shift-audioshift-audio 00.58 earlier 1sMove the speech block starting near that time. gap sets the silence that ends the block (default 2 s).
narratenarrate 00.48-00.52 "Click Next."Add AI voice at a time. Window end optional.
replace-voicereplace-voice 02.05-02.08 "New text."Mute that part and speak new text there.

Times are mm.ss (01.05 = 1 min 5 s); 1:05 and 65s also work. All times in one batch refer to the video as it is now. Apply places audio edits first and cuts last, so earlier cuts never shift later times.

4. Quick one-off edits: video_edit.py

python3 video_edit.py cut demo.mp4 --range 00.10-00.17 --range 01.05-01.20
python3 video_edit.py narrate demo.mp4 --start 00.30 --end 00.40 --text "Tap Continue."
python3 video_edit.py narrate demo.mp4 --script narration.txt     # START-END | text
python3 video_edit.py narrate demo.mp4 --start 00.30 --text "Hi" --replace
python3 video_edit.py info demo.mp4
python3 video_edit.py                                              # interactive

Timing and final video

Each line is anchored to measured speech onset, starts --lead (1.0 s) early, and must end within --end-grace (0.5 s) of the original end. Lines that do not fit are sped up to --max-tempo (1.3x) or shortened by the model.

flowchart TD
  A["Whisper start / end"] --> B["refine_edges
snap to silence boundaries from ffmpeg silencedetect"]
  B --> C["assign_slots
place = start - lead
slot_end = min(next place - 0.05, end + grace)
slot = slot_end - place, min 0.8 s"]
  C --> D["TTS clip, silence trimmed at both ends"]
  D --> E{"clip length / max_tempo
fits slot?"}
  E -->|yes| F["atempo = max(1, length / slot)"]
  E -->|no| G["LLM shorten to char limit
up to 3 rounds"] --> D
  F --> H["adelay to place, amix all lines"]

Design decisions

Measured onset, not Whisper time

Whisper timestamps run late by 0.1 to 0.7 s. refine_edges snaps starts to real speech onsets found with ffmpeg silencedetect. Disable with --no-snap.

Hash-keyed speech cache

Clip path is a SHA-1 of TTS model, voice, style and text. Re-runs and re-applies only pay for changed lines.

Fit loop before overlap

Speed-up is capped at 1.3x for naturalness. Beyond that the LLM shortens the text, at most three rounds, then a warning is logged.

Two-model validation

A second, independent transcription catches mishearings and invented lines one model produced. Used as flags and as rewrite evidence, never as ground truth.

Edits are data

Edit words parse to dicts stored in project.json. Plan and render are pure functions of the current file plus that list, so apply is repeatable and undoable.

Safe state changes

project.json is written to a temp file then os.replaced. A failed render deletes its partial output and leaves pending edits untouched.

No project knowledge in code

Glossary and naming rules live in a user text file passed with --context-file. The prompts in config.py stay generic.

One status line, full JSON log

Terminal shows a spinner line only. Every OpenAI request, ffmpeg command and human action goes to the log, rewritten per event so crashes keep it.

Logs

Every run writes logs/log_<timestamp>.json. Levels: success, info, warning, error, debug (every OpenAI request with status, timing, retries, and every ffmpeg command). The API key is redacted everywhere.
